Download MacBook FaceID

The Mac app is published as a GitHub Release. This page does not host the binary — it sends you to the latest tag so you always get the current build.

Latest GitHub Release All releases

Install

  1. Open the latest GitHub Release.
  2. Download MacBook-FaceID.dmg or MacBook-FaceID.zip.
  3. Open the disk image (or unzip) and drag MacBook FaceID to Applications.
  4. First launch: right-click the app → Open. CI builds are unsigned unless you notarize them yourself.

You can also clear the quarantine flag and launch from Terminal:

xattr -cr "/Applications/MacBook FaceID.app"
open "/Applications/MacBook FaceID.app"
Unsigned builds will trip Gatekeeper. That is expected for ad-hoc CI artifacts. After it opens, continue with permissions and first-run setup.

Requirements

  • macOS 14 Sonoma or later (Apple silicon or Intel).
  • A camera: built-in webcam or an external display camera you select in Settings.
  • Notch placement is designed for 14″ / 16″ MacBook Pro and notched MacBook Air. Other Macs get a floating pill.

What you are downloading

A free macOS utility named MacBook FaceID. The feature in the UI is called Face Unlock. It enrolls a local face embedding and types a saved login password at the lock screen. It is not TrueDepth Face ID and it does not use the Secure Enclave.

Current published tag at the time this site shipped: v0.2.0. Always prefer the latest URL rather than a pinned asset link.

Build from source

If you would rather compile it yourself, clone plut0000/MacBook-FaceID, open MacBookFaceID/MacBookFaceID.xcodeproj in Xcode 15+, and run the MacBookFaceID scheme. The README has the xcodebuild invocation.
