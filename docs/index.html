Face Unlock for Mac.

A notch-native scan that watches for you, then types the password you saved. Built for MacBooks with a webcam — not for pretending this is iPhone Face ID.

Read this first

A Mac webcam sees a flat 2D image. iPhone Face ID builds a 3D depth map. This app is a convenience feature. It is not TrueDepth Face ID, it does not use the Secure Enclave, and it is not a security upgrade.

  • Heavy liveness can reject a printed photo or a still image on a phone with reasonable confidence. It does not reliably defeat a video of you.
  • macOS has no API that lets a third-party app authorize a login, so unlock works by typing your stored password at the lock screen (Accessibility).
  • Do not use this on a shared Mac you do not control.

What you get

The same job as other Mac face-unlock utilities: enroll locally, watch the lock screen, type the password if it is you. The island, enrollment, liveness, and embedding pipeline in this repo are original.

Notch island

A closed pill in the hardware notch expands into a scan with success and failure. No notch? A floating pill at the top of the display.

Nine-pose enroll

Turn your head in nine directions. Each accepted frame becomes a 512-number embedding. The image is discarded.

Liveness checks

Light rejects screen glare and a device-shaped frame. Heavy also looks for blinks, head motion, and 3D-ish landmarks. Or turn it off.

Encrypted vault

Embeddings and the login password sit in an AES-256-GCM vault. The key is in Keychain behind Touch ID or your device password.

Idle auto-lock

The session key lives in memory only while authorized. After the idle interval you choose, Face Unlock will not type until you authorize again.

No telemetry

Frames stay in memory. There is no analytics account, no cloud sync, and no network requirement. See privacy.

How unlock works

An unlock requires all of these: an authorized session, an actual lock screen, a matching enabled identity, liveness (unless you turned it off), and Accessibility to type.

Enroll on this Mac

Camera frames are processed in memory. The app stores embeddings, not photos, then encrypts them in Application Support.

Watch lock, wake, or space

Pick any combination in Settings → Recognition. Space at the lock screen is listen-only; the key still reaches macOS.

Match, then type

On match, the vault password is typed into the lock-screen field with Accessibility (CGEvent). Same pattern as other Mac face-unlock utilities.

What it cannot do

These limits are by design. FileVault pre-boot and the login window before a session are outside what a user-space app can touch.

Situation What happens
Screen lock after you are logged in Island scans; on match and liveness, types the vault password.
Lid closed The camera cannot see you.
FileVault / EFI pre-boot, or the login window before any user session Cannot unlock. The app only runs inside an existing user session.
Fast User Switching / another user’s login window Not supported.
Session auto-locked after idle A face may match, but the password is not typed until you authorize again.
